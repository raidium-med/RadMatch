# Attribute-errors few-shot examples (chest-ct)

Stage 3b examples, most derived from the matches of the corresponding `chest-ct/matching/example_N.json`. A status-inversion pair reaches Stage 3b too and expects `[]` (prompt rule 1): the inversion is scored upstream.

| File | Drawn from | Highlights |
|------|------------|------------|
| `example_1.json` | matching/example_1 (heart-size INC pair excluded) | Bronchiectasis left vs right apex: no error here, the side is Stage 3a `laterality`'s (minor on this routine finding) + minor severity on coronary calcifications (moderate vs severe, one step) + aortic arch 4.1 vs 3.6 cm across the 4 cm threshold (major measurement) + clean hepatic lesion pair |
| `example_2.json` | findings_gt + findings_pred example_2 (hepatic INC pair excluded) | Minor measurement error on the largest pulmonary nodule (2.5 x 1.6 vs 3.1 x 1.7 cm, under 20 % difference) + clean node pair; the prior sizes are carried by `comparison`, not `measurements` |
| `example_3.json` | findings_gt + findings_pred example_3 (pleural-effusion INC pair excluded) | LLL nodule 11 vs 13 mm between the 8 and 15 mm thresholds (minor measurement) |
| `example_4.json` | matching/example_4 (status inversions excluded) | Major diagnosis for bulla vs pneumothorax, side differences left to Stage 3a `laterality` (no site or extent error) for unilateral vs bilateral; no error for synonyms, a sub-threshold node, a post-surgical state |
